# Evaluacion de Producto - Programacion Avanzada I

## Objetivo
Comparar los algoritmos de ordenamiento Shell Sort y Quick Sort mediante
experimentos reproducibles en C++.

## Algoritmos
- Shell Sort
- Quick Sort

## Estructura del proyecto
- src/: codigo fuente en C++.
- include/: archivos de cabecera.
- results/: resultados experimentales.
- docs/: documentacion e informe.

## Metodologia
Se medira el tiempo de ejecucion y se registraran metricas de los algoritmos
con diferentes tamanos y patrones de entrada.

Los resultados se incorporaran despues de ejecutar y validar los experimentos.

## Compilacion
La instruccion de compilacion se agregara cuando se incorpore el codigo fuente.
